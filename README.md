# 老张健身工作台

个人健身记录与数据分析应用：训练 / 饮食 / 身体状态三位一体，增肌塑形目标导向。

## 功能

- **训练记录**：预置 40+ 力量动作（按肌群分类）+ 自定义动作；组数×次数×重量记录；自动对比每个动作的上次成绩与历史最好（估算 1RM），辅助渐进超负荷；训练草稿防丢
- **饮食记录**：一句话记账（如「鸡蛋2个 牛奶一杯」），内置 48 种中式食物库自动估算热量与三大营养素；每日摄入对比增肌目标（热量小盈余 + 蛋白质 1.8g/kg）；餐食照片仅存本设备、3 天自动清理
- **身体状态**：体重/体脂记录与趋势曲线；进度照片每 ~10 天一张存云端（私有桶，仅本人可见），时间轴对比体型变化，超期自动提醒
- **仪表盘**：今日热量/蛋白质进度、本周训练概况、体重趋势、目标达成度，一眼看清状态
- **目标设定**：当前/目标体重、身高、年龄、活动水平、训练经验、每周训练天数，驱动全应用的目标计算
- **周报导出**：一键生成结构化 Markdown 周报，复制给任意 AI 即可获得个性化训练/饮食建议
- **PWA**：手机浏览器「添加到主屏幕」即可像原生 App 一样使用，支持离线打开

## 技术栈

- 前端：Vite + React（手机优先响应式）
- 后端：Supabase 免费版（邮箱密码登录 + PostgreSQL + RLS 行级安全 + 私有存储桶）
- 部署：GitHub Pages（`gh-pages` 分支直推）

## 本地开发

```bash
npm install
npm run dev        # 开发服务器 http://localhost:5173
npm run build      # 生产构建
bash deploy.sh     # 一键部署到 GitHub Pages
```

环境变量见 `.env.example`（`VITE_SUPABASE_URL` / `VITE_SUPABASE_ANON_KEY`，anon key 为公开密钥，数据安全由 RLS 策略保障）。

## 数据库

`supabase/` 目录下的 SQL 按模块组织，在 Supabase SQL Editor 中依次执行即可初始化（均幂等可重复执行）：

1. `m2-training.sql` — 动作库 / 训练日 / 训练组
2. `m3-diet.sql` — 食物库 / 餐次记录 / 用户资料
3. `m4-body.sql` — 身体数据 / 进度照片 / 目标字段 / 存储桶

## 路线图

- AI 照片识别：餐食照片 → 自动估算热量；全身照 → 估算体脂率（多模态 AI 接口）
