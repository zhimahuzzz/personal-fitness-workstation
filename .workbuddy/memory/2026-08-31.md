## M3 二次修复：保存报 "Could not find the 'photo' column of 'meals'"
- 根因：meals 表设计上无 photo 列（照片只存本设备 localStorage），但 insert  payload 里混入了 photo 键。代码里其实有解构剥离，用户浏览器大概率跑了旧 JS（手机端页面未刷新）；为彻底防呆，insert 改为显式列白名单（meal_type/note/items/kcal/protein/carbs/fat），不再展开整个对象
- 已用 curl 确认 Vite 伺服的是修复后代码；提醒用户硬刷新（Ctrl+Shift+R / 手机端关闭标签页重开）再测

## M3 追加修复（晚间用户实测）
- 不拍照点保存报 "Could not find the 'photo' column of 'meals'"。根因：AddMealSheet 保存载荷始终带 photo 字段（无照片时为 null），Diet onSave 把 ...data 整个展开进 supabase insert，PostgREST 对未知列无论值是否为 null 都拒绝。修复：onSave 先 `const { photo, ...mealRow } = data` 剥离 photo 再 insert，photo 仅写 localStorage
